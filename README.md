# Codeial

**Codeial** is a social media application built using Node.js, Express.js, MongoDB, and other frameworks. This platform allows users to connect, share posts, and interact with each other in a seamless manner.

## Features

- **User Authentication**: Secure login and registration using Passport.js and JWT.
- **Post Creation**: Users can create, edit, and delete posts.
- **Comment System**: Engage with posts through comments.
- **Responsive Design**: Optimized for various devices.

## Technologies Used

- **Backend**:
  - Node.js
  - Express.js
  - MongoDB
  - Passport.js
  - JWT

- **Frontend**:
  - HTML
  - CSS
  - JavaScript
